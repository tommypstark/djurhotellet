# Djurhotellet

Ett enkelt Java-program för att hantera incheckade katter på ett djurhotell.

## Funktioner

• Skapa katter med namn, ras och chipnummer.

• Skydda kattens uppgifter med privata fält och getters.

• Lagra katter i en privat lista i KattHotell.

• Checka in nya katter.

• Förhindra att flera katter har samma chipnummer.

• Lista alla incheckade katter.

• Visa ett meddelande om hotellet är tomt.
